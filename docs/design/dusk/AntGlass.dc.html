ANATOMY · FIVE LAYERS, BACK TO FRONT

  1. 1 · RefractionBackdrop blur 6–16 px, saturate 180–200%. Kept light so the photo stays readable through it.
  2. 2 · Body135° white wash. Clear 16→4%, prominent 46→16%. Orbs use a radial highlight from the top-left.
  3. 3 · Rim lightInset 1 px white along the top edge (55–100%) and a faint one along the bottom: the glass catching light.
  4. 4 · Chromatic edgeRed tint on the left edge, blue on the right, 14–28%. Stand-in for the library’s aberrationIntensity 2.
  5. 5 · LiftSoft dark drop shadow, 18–44 px. Selected items also scale 1.04 with a 240 ms spring.

BUILDING IT IN THE APP

liquid-glass-react is a web component (React DOM, SVG displacement), so it will not run in the React Native phone app. Its defaults are still a good target: displacementScale 70, blurAmount 0.0625, saturation 140, aberrationIntensity 2, elasticity 0.15.

On iOS 26 the system has a native glass material; reach it from React Native through a native-module wrapper (check which one is current before choosing). On older iOS and Android, fall back to a blur view plus layers 2–5 above, which is what these mockups draw.

Keep text on glass white and bold with a 1–2 px shadow; never put body copy on prominent glass over a bright sky.
